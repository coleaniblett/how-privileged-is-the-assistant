# Moved paths, 2026-11-06 (branch `repo_cleanup`)

The repository was reorganised by measure and pilot (`docs/decisions.md`, 2026-11-06). Every move was a `git mv` (history follows
with `git log --follow`), and every reference in code, launchers, tests and docs was rewritten. Raw records (csv, jsonl, json
manifests, logs) still show the paths they were written to. Code paths and file names inside each directory are unchanged.

**Other checkouts** (remote machines) keep untracked files, such as activation fits (`*.npz`) and generations, at the old paths.
After pulling, run `bash scripts/migrate_untracked_2026-11-06.sh` once from the repo root: it moves whatever is still at an old
path to the new one (never overwriting) and lists what it moved.
