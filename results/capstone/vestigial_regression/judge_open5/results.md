# Vestigial regression judge arm: open-opener condition

Generated by `python -m measures.vestigial_regression.analyze_open5` from `results/capstone/<family>/vestigial_regression/judge_open5/` (judge prompt v3, `claude-sonnet-5-5`). Five complete-but-open user openers, 120 samples each per checkpoint. Each post-trained checkpoint against its family's base. Rates in percentage points; 95% bootstrap CIs resample samples within each opener (base and checkpoint independently); the openers are fixed conditions, so conclusions are about these five. Pooled = openers equally weighted.

Rule (README, frozen with the labels 2026-11-05): fires if the pooled non-user-voice rate change has its CI above zero and the change is positive at 4+ of 5 openers; the minimum rate difference is OPEN and not applied. `closed_immediately` is reported on its own for open openers, a rule set **after** automated counts were seen (trained OLMo closes "Can I tell you something?" at once). The generations were judged blind; the condition's design was motivated by earlier data. **Contamination can be checked for OLMo only.** The judge is not yet validated on v3 (a fresh blind sheet is pending).
