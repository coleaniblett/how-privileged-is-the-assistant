# Overgeneralization results: the measure and its pilots

Every overgeneralization result outside the main run lives here, one directory per pilot (reorganised 2026-11-06; old paths are
listed in `docs/moved_paths_2026-11-06.md`). The launchers for each pilot are in the matching `scripts/overgeneralization/<pilot>/`;
the code is in `extras/` (pilots) and `measures/overgeneralization/` (the measure). Plans, deviations and results are logged by date in
`docs/decisions.md`; the working summary for the presentation is `measures/overgeneralization/presentable_findings.md`.

**What counts toward a verdict:** only the pre-registered persona-carryover test (confirmatory set) and the user-slot arm (on the main
run's generations, in `results/capstone/<family>/overgeneralization/`). Everything else here is exploratory and outside every verdict;
many pilots were planned after earlier results were seen and say so in their reports ("NOT BLIND", "POST-HOC"). Contamination can be
checked for OLMo only.
